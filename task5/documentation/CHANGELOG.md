# Changelog

All notable changes to this project are documented in this file.
Versioning follows a simple semantic versioning approach.

***

## v1.0.0 – Initial Release

--> Implemented a modular GPIO driver for LED control

--> Added UART driver and command-based user interface

--> Developed a UART-controlled mode machine with multiple runtime modes (blink, breathe, pattern, game)

--> Integrated software timer–based delays for mode timing

--> Enabled dynamic mode switching without system reset

--> Added UART help menu for improved usability and demonstration
